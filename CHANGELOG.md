# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-07-03

### Added
- Added support for pasting images directly from the clipboard (`Ctrl+V` on Windows/Linux, `Cmd+V` on macOS).
- Introduced a visual "Pegar imagen" / "Paste image" button in the initial upload screen.

### Fixed
- Fixed localization linter warnings by providing descriptions for all translation keys in `app_en.arb`.
- Resolved potential horizontal overflow layout issue on smaller screens in the upload screen by replacing the button row with a wrap container.

## [1.0.0] - 2026-06-30

- Initial release of Unback. Offline, secure and high-performance background removal.
